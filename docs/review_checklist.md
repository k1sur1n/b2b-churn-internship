# Чек-листы перед PR

Проходите **только свою неделю**. Пункты других недель к вам ещё не относятся.

**Общее для всех недель:** Pull Request открывается из ветки недели в `main`
**вашего собственного форка**, а не в учебный репозиторий. GitHub подставляет
учебный по умолчанию — проверьте поле `base repository`. В адресе готового PR
должен стоять ваш логин.
