# Неделя 4 — Эксперимент A/B/C, интерпретация, защита

> Краткая карточка. **Полная версия — рабочая тетрадь, раздел 8.**

**Даты:** 24.08 – 30.08 · **Ветка:** `week4-experiment` · **Ноутбуки:** `05_segments_experiment.ipynb`, `06_final_report.ipynb`

## Цель

Ответить на главный вопрос курса — одна модель или по одной на сегмент — и объяснить результат на языке бизнеса.

## Шаги

1. Написать **одну** функцию `run_experiment(...)` и вызвать её трижды:
   - **A** — единая модель, `segment`/`product` в признаки не входят
   - **B** — единая модель, `segment`/`product` входят
   - **C** — своя модель на каждый сегмент; предсказания трёх моделей склеиваются в один вектор по исходному порядку строк теста
2. Таблица метрик: подходы × (ROC-AUC, Lift@10%), в целом и внутри каждого сегмента.
3. `bootstrap_auc_diff` — смотреть на доверительный интервал разницы, а не на «кто чаще выиграл».
4. Feature importance + SHAP summary (на подвыборке 2000–5000 строк) + разбор 1–2 клиентов.
5. `06_final_report.ipynb` — десять разделов, каждый 1–3 абзаца, читается без кода.
6. Презентация 5–7 слайдов.

## Одинаковые условия

Один `dataset`, один `split_by_time`, один `seed`, одни гиперпараметры, один набор признаков — кроме того, что различается по определению подхода. Иначе эксперимент не отвечает ни на какой вопрос.

## Чего ожидать

Заранее правильного ответа нет. Различия могут оказаться небольшими — тогда вывод «разница незначима» такой же полноценный результат, как и любой другой. Посмотрите, сколько уходов попадает в обучение каждой сегментной модели подхода C: это число понадобится, чтобы объяснить результат.

## Пять подсказок

1. Ожидаемый результат подхода C — просадка на крупном бизнесе. Это ответ на исследовательский вопрос, а не баг.
2. Разница 0.005 AUC — шум. Без интервала не говорите «лучше».
3. Отчёт пишется по ходу недели: разделы 1–5 — пересказ уже сделанного, их можно закрыть в понедельник.
4. Слайды делаются из отчёта. Один график — один слайд.
5. Оставьте 2–3 предложения на странные паттерны из журнала — их разбирают в конце защиты.

## Минимум, если не успеваете

A и B (без C), bootstrap, feature importance без SHAP, отчёт и слайды. Без отчёта и слайдов защита не состоится.
