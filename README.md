# Подготовка к стажировке: прогнозирование оттока B2B-клиентов

Учебный репозиторий для подготовки студентов-стажёров к проекту «Модель
прогнозирования оттока (churn) B2B-клиентов телеком-компании». Курс рассчитан
на **4 недели**, идёт параллельно с еженедельными семинарами и асинхронным
ревью в Pull Request'ах.

## Начните отсюда

**Полное описание курса — в `docs/rabochaya_tetrad_stazhera.pdf`.** Это единственный
источник правды: постановка задачи, все понятия, пошаговые планы недель,
подсказки, FAQ, глоссарий. Скачать можно тут: https://clck.ru/3VEUBy

Файлы в `docs/weekN_*.md` — краткие карточки недель, выжимка из тетради.
Если карточка и тетрадь расходятся — верьте тетради и сообщите руководителю.

## Как пользоваться репозиторием

1. **Форкните** этот репозиторий к себе в GitHub.
2. Клонируйте свой форк локально.
3. На каждую лабораторную создавайте отдельную ветку: `week1-eda`,
   `week2-dataset`, `week3-baseline`, `week4-experiment`.
4. По готовности недели откройте **Pull Request** из своей ветки в `main`
   **своего собственного форка** и **пришлите ссылку на PR руководителю в чат**.

   > **Pull Request делается в ваш репозиторий, а не в этот.**
   > GitHub на странице создания PR по умолчанию подставляет исходный
   > репозиторий в поле `base repository` — поменяйте его на свой.
   > Проверка: в адресе открытого PR должен стоять ваш логин.
   > Подробно, по шагам — рабочая тетрадь, раздел 4.3.

   (Кнопка «Reviewers» на личном форке работает только для тех, у кого
   есть доступ к репозиторию, поэтому просто пришлите ссылку.)
5. После фидбека вносите правки в той же ветке — PR обновится автоматически.
6. Смёрженный `main` после недели 4 — ваш финальный артефакт для защиты.

## Что где живёт

| Куда | Что туда идёт |
|---|---|
| `src/*.py` | Функции, которые вызываются больше одного раза |
| `notebooks/*.ipynb` | Вызовы этих функций, графики, таблицы, проверки |
| `docs/journal_<имя>.md` | Решения, определения, наблюдения — всё, что не код |
| PR | Вся ветка целиком; отдельно ничего прикреплять не нужно |

## Данные

В `data/raw/` уже лежит учебный синтетический датасет: **50 400 клиентов,
~1 073 000 строк помесячного потребления** за январь 2024 — июнь 2026.
`clients.xlsx` + 30 помесячных CSV в `data/raw/usage/`. Скачивать ничего
не нужно, данные приходят вместе с форком. Описание столбцов —
в `docs/data_dictionary.md`.

## Правила проекта

- Файлы в `data/raw/` — только для чтения.
- Признаки строятся **только** из окна наблюдения, таргет — **только**
  из окна прогноза. Нарушение — утечка данных (data leakage).
- Между окном наблюдения и окном прогноза есть слепой зазор в 2 месяца:
  прогноз должен оставлять отделу удержания время на реакцию.
- Разбиение train/test — только по времени (out-of-time), никогда случайным
  перемешиванием.
- `data/processed/` в git не попадает. В PR идёт код, который его собирает.
- Ведите `docs/journal_<имя>.md` и коммитьте в конце каждого рабочего дня.
